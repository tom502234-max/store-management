# 임금명세서 발급

근무자별 근무시간을 입력하면 임금명세서를 계산해 PDF로 내보내는 Next.js 웹앱입니다.
명세서 양식은 `근무자_급여.xlsx`의 `양식` 시트(기존 `임금명세서_YYMM_이름.pdf`)와 같습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

### 휴대폰에서 사용하기 (같은 Wi-Fi)

```bash
npm run build
npm start
```

PC의 IP 주소(예: `http://192.168.0.10:3000`)를 휴대폰 브라우저에서 엽니다.
`공유 · 저장` 버튼(여러 PDF를 한 번에 ‘파일에 저장’)은 HTTPS에서만 동작하므로, Vercel 등에 배포하면 휴대폰에서도 표시됩니다.
HTTP 접속에서도 개별 다운로드와 ZIP 받기는 그대로 사용할 수 있습니다.

## GitHub Pages 배포

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy-pages.yml`)가 정적 사이트로 빌드해 배포합니다.

- 주소: https://tom502234-max.github.io/store-management/
- 처음 한 번만: 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정
- GitHub 무료 플랜은 공개(Public) 저장소에서만 Pages를 쓸 수 있습니다.

HTTPS로 제공되므로 휴대폰에서도 `공유 · 저장` 버튼이 동작합니다.
근무자 데이터는 서버로 전송되지 않고 각 사용자의 브라우저에만 저장됩니다.

## 사용법

1. **발급 정보** — 귀속 년월, 지급일, 시급(기본 11,000원), 고용보험 요율(기본 0.9%)
2. **근무자** — 이름과 근무시간 입력. 엑셀에서 이름·시간 열(또는 이름·급여·시간)을 복사해 이름 칸에 붙여넣으면 여러 명이 한 번에 들어갑니다.
3. **파일명 · 내보내기** — 파일명 형식에 변수를 넣어 지정합니다.

| 변수 | 의미 | 예 |
| --- | --- | --- |
| `{이름}` | 근무자명 | 홍길동 |
| `{년월}` | 귀속 년월 (YYMM) | 2609 |
| `{연도}` | 귀속 연도 | 2026 |
| `{월}` | 귀속 월 | 09 |

기본값 `임금명세서_{년월}_{이름}` → `임금명세서_2609_홍길동.pdf`

### 근무자 목록 저장 · 불러오기

입력 중인 내용은 브라우저(localStorage)에 자동 저장되어 새로고침해도 남아 있습니다.
이와 별도로 **귀속 년월별 목록**을 보관해 두고 다시 불러올 수 있습니다.

- **현재 목록 저장** — 지금 목록을 현재 귀속 년월로 저장합니다(같은 달이 있으면 덮어씀).
- PDF를 내보내면(개별·전체·ZIP·공유) 그 달 목록이 **자동 저장**됩니다.
- **목록 불러오기** → 저장된 달을 골라
  - **이름만**: 근무자 이름만 불러오고 근무시간은 비웁니다. 새 달 입력용.
  - **전체**: 근무시간과 귀속 년월·지급일·시급·요율까지 그대로 불러옵니다. 재발급용.
- 불러온 직후에는 **되돌리기**로 이전 상태로 돌아갈 수 있습니다(내용을 고치기 시작하면 사라짐).

저장 위치는 사용 중인 브라우저이므로, 같은 기기·같은 브라우저에서만 보입니다.
시크릿 모드이거나 브라우저 데이터를 지우면 함께 삭제됩니다. 최대 36개월분을 보관합니다.

## 계산

- 기본급 = 근무시간 × 시급 (원 단위 반올림)
- 고용보험 = 기본급 × 요율, 10원 미만 절사 (엑셀 `ROUNDDOWN(기본급*0.009,-1)`과 동일)
- 실지급액 = 기본급 − 고용보험

## PC·모바일 결과 동일성

PDF는 화면 캡처가 아니라 [@react-pdf/renderer](https://react-pdf.org)로 브라우저 안에서 직접 생성합니다.
기기에 설치된 글꼴 대신 `public/fonts`의 Noto Sans KR(한글·라틴 서브셋, SIL OFL)을 PDF에 내장하고,
숫자 표기도 기기 언어 설정과 무관하게 처리하므로 어떤 기기에서 내보내도 같은 PDF가 만들어집니다.
(한자는 서브셋에 포함되지 않습니다.)

폰트는 로딩을 줄이기 위해 두 벌로 나뉘어 있습니다.

- `NotoSansKR-Common-*.woff` (약 250KB): 자주 쓰는 한글 2,350자(KS X 1001) + 라틴 — 기본으로 사용
- `NotoSansKR-Full-*.woff` (약 900KB): 한글 11,172자 전체 — 이름에 희귀 한글(예: 똠, 햏)이 있을 때만 내려받음

어떤 폰트를 쓸지는 이름 글자만으로 정해지므로 기기와 무관하게 같은 결과가 나옵니다.
Common 폰트의 글자 목록은 `lib/pdf/fontCoverage.ts`와 일치해야 합니다.

미리보기는 pdf.js로 실제 PDF를 그려서 보여 주므로, 화면에 보이는 것이 내려받는 파일과 같습니다.
미리보기가 화면에 보일 때만 pdf.js를 불러옵니다(모바일에서는 스크롤해서 내려갔을 때).
